Reference-Matching Design Rules

Most important rule

The supplied BlueWave screenshot is the visual benchmark.

The Mokshith Enterprises website should preserve the reference's visual
character much more closely than a generic "solar website"
interpretation.

Think:

editorial + photographic + minimal + premium + renewable energy

Not:

dashboard + SaaS + card-heavy + neon-tech

Layout language

Use a narrow, elegant content container for text-heavy sections.

Use large margins and generous vertical spacing.

The page should breathe.

Avoid filling every available area with UI components.

Use large photography to create rhythm.

The repeated visual pattern should be:

quiet whitespace → content → large image → whitespace → cinematic
full-width image → content → dark cinematic section → editorial content
→ contact

Section proportions

Hero: Large / immersive.

Solutions: Tall editorial sections with approximately equal visual
weight between image and text.

Full-width image sections: High visual impact and generous height.

Benefits / insights: Compact and clean.

Mission: Dark, atmospheric and visually deep.

Contact: Large but controlled form panel.

Footer: Dense enough to feel complete, but still spacious.

Image treatment

Images are a core part of the design, not decoration.

Use realistic photography.

Preferred subjects: - rooftop solar panels - Indian homes - commercial
buildings - factories - solar farms - engineers inspecting
installations - landscapes with solar infrastructure - clean blue
skies - golden-hour solar scenes

Do not reuse the same image repeatedly.

Do not use obvious low-quality stock images.

Keep image corners mostly restrained. Do not turn every image into a
heavily rounded card.

Use subtle image cropping and object positioning to create an editorial
appearance.

Color behavior

The reference relies heavily on white space.

Approximately: - 65--75% light/white visual space - 15--25% dark navy
sections - blue/environmental photography for major visual breaks -
green only as a supporting solar accent

Use dark navy for: - mission section - footer - important CTAs where
appropriate

Use white for: - main content sections - solution backgrounds -
editorial cards

Typography behavior

Headlines should be large but not excessively bold.

Use sentence-case headlines.

Avoid giant all-caps marketing text.

Use small eyebrow labels above major headings.

Body copy should be short.

The reference works because the copy does not overwhelm the photography.

Recommended hierarchy:

Eyebrow: 10--12px, uppercase, letter spacing

Section heading: 36--56px desktop

Body: 14--17px

CTA: 13--14px

Mobile headings: 28--38px

Navigation

Navigation should be visually light.

Desktop: - logo on left - simple links - CTA on right

Initially overlay the hero.

After scrolling: - solid light or dark background - subtle transition -
maintain the same compact height

Do not create a giant navbar.

Alternating solutions

This is one of the most important reference characteristics.

Do NOT convert Residential, Commercial and Industrial into three
identical cards.

Instead:

Section 1: [IMAGE] [TEXT]

Section 2: [TEXT] [IMAGE]

Section 3: [IMAGE] [TEXT]

Maintain generous spacing between each.

On mobile: [IMAGE] [TEXT]

then the next section.

Full-width sections

Use full-bleed photography to separate major content groups.

The image should extend edge-to-edge.

Text can sit inside a constrained content area.

Use a subtle overlay when required.

Do not place excessive UI over these photographs.

Dark mission section

The dark section should feel cinematic rather than like a footer.

Use: - deep navy/near-black background - subtle earth/solar/space
imagery - white typography - small supporting copy - restrained CTA

This should be one of the visual peaks of the website.

Editorial cards

Insights/news cards should resemble a modern editorial layout.

Use: - image - small category/date - title - short description

Keep borders extremely subtle.

Do not use oversized shadows.

Do not use colorful icon backgrounds.

Buttons

Buttons should be simple.

Primary: dark navy or strong solar blue.

Secondary: transparent / outlined / minimal.

Use: - slight translate or scale on hover - smooth transition - no
exaggerated glow

Forms

The contact form should visually echo the reference.

Place a clean white form surface over or against an atmospheric
background.

Use generous internal spacing.

Desktop: two columns where appropriate.

Mobile: one column.

Inputs should be minimal and modern.

Avoid giant rounded inputs.

Scroll behavior

The page should feel smooth.

Use: - section reveal - image reveal - slight parallax - navbar
transition - counter animation where used

Animations must never interfere with reading or scrolling.

Anti-patterns

Do NOT introduce: - huge gradient blobs - neon green glow -
glassmorphism everywhere - excessive rounded cards - 3D solar panels
floating around the page - animated sun graphics everywhere - excessive
particles - cartoon illustrations - generic AI illustrations -
dashboard-like layouts - huge statistics dominating the page - excessive
badges - fake certifications - fabricated company claims

Reference fidelity checklist

Before considering the page finished, compare it against the supplied
reference and verify:

[ ] Hero is immersive and photographic
[ ] White space is generous
[ ] Solutions use alternating editorial layouts
[ ] Full-width photographic breaks exist
[ ] Benefits use clean visual cards
[ ] Dark cinematic mission section exists
[ ] Insights are editorial, not dashboard cards
[ ] Contact has a prominent clean form panel
[ ] Footer is deep navy and structured
[ ] Typography is elegant and restrained
[ ] Website does not feel template-generated
[ ] Mobile layout is intentionally redesigned
[ ] No horizontal overflow
[ ] No invented business facts
[ ] Mokshith Enterprises branding is used consistently

Final quality bar

The finished website should make someone familiar with the supplied
screenshot say:

"Yes, this clearly follows that same premium design direction."

At the same time, it must still be unmistakably:

MOKSHITH ENTERPRISES

The reference determines the visual language. Mokshith Enterprises
determines the identity and content.
